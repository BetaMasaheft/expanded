# Betamasaheft Expanded data

The contents of this repository are automatically generated by the betamasaheft expansion script.

Over time data errors have been introduced into various files on production. Validation is disabled on CI for that reason.

These commands will produce more detailed reports of the most common errors. The errors can mostly be fixed by re-expanding the files in question.

```shell
grep -l 'source-url' --include='*.xml' -r . > source-url_report.txt
find . -type f -name "*.xml" | xargs xmllint --noout 2>&1 | tee wellformedness-report.txt
```
